Diagnostics

Every error and warning the compiler reports has a code: E- for an error or W- for a warning, the area, and a number that stays with the message (E-TYPE-0042). adm check prints it beside the place, --json gives it as code, and editors show it with a link here. What the C compiler, nvcc, zig, rustc, go and the linker report on your code is shown the same way, at the line of the C, Zig, Rust or Go file, at the line of a cuda def body, or at the declaration a missing symbol belongs to. adm explain E-TYPE-0042 prints one entry in the terminal. Where the compiler knows the edit that resolves a diagnostic, it attaches a fix: editors offer it as a quick fix, adm check --fix applies them, and adm check --json lists them under fixes. In the messages below, %s and its kin stand for the names and types the compiler fills in.
