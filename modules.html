Standard Library

The standard library ships with the compiler under the std namespace. Import any of it with use:

imports.adm 
use std.strings
use std.net.http
use std.data.encoding::(json)

Per-module API reference is being generated - the pages below are placeholders for now.

Core

std.strings

Text manipulation, searching, and formatting. Reference coming soon.

std.bytes

Byte buffers and readers. Reference coming soon.

std.math

Numeric functions plus std.math.geom for geometry types, std.math.bezier (Bézier curves and the CSS cubic-bezier solver) and std.math.easing (the easings.net curves, CSS steps and a damped spring). Reference coming soon.

std.units

Dimension types and units for quantity literals: the SI base dimensions plus angle and data size, around forty derived dimensions (Speed, Force, Energy, Voltage, DataRate, …), SI units with every prefix, the accepted non-SI units (min, h, L, °C, kWh, bar, …), data sizes with decimal and binary prefixes, and the levels dB, dBFS, dBm and dBW. parseUnit reads quantities from text and quantity builds one from a number. The catalogue lists them all.

std.time

Clocks, durations, formatting, and cron expressions. Time.equals compares the wall clock only; since measures on the monotonic clock when both times carry one (both came from now()), otherwise on the wall clock. Reference coming soon.

std.errors

Error construction, wrapping, and inspection. Reference coming soon.

std.data.collections

Sequences (List, LinkedList, DoublyLinkedList, Deque, Queue, Stack, RingBuffer), bit sets, hash and ordered maps (HashMap, SortedMap, OrderedMap, MultiMap), sets, heaps and priority queues, trees (BinaryTree, BST, AVLTree, RedBlackTree, BTree, BPlusTree, Trie, RadixTree), graphs with Dijkstra, sparse arrays, a Bloom filter and an LRU cache. std.data.collections.sort sorts any type that implements Comparable<T>, and std.data.collections.search finds a value in a list. Both let you pick the algorithm. Doubly linked structures keep their back pointers weak, so dropping a list frees its nodes. Reference coming soon.

std.data.semver

Semver: parse, the version parts, precedence comparison against a version or a string, and satisfies(range) with ||, operators, ~, ^, wildcards and hyphen ranges. Reference coming soon.

std.i18n

Locales, languages, regions, currencies, time zones, number and date formats, plural categories. Reference coming soon.

std.validations

Input validation helpers and validating parameter annotations. Reference coming soon.

System

std.os

Filesystem, paths, processes, and environment. Reference coming soon. run(command, input) and output(command) start a program through Runtime.run and need adm.runtime.spawn.

std.io

Reader, Writer, Closer and their combinations - interfaces only, implemented by the types that own the data (std.bytes.Buffer, std.os.File). read(buf) may return fewer bytes than asked; at the end of the stream it returns 0 for a non-empty buffer, without an error, on every call from then on. readFull loops until the buffer is full and fails if the stream ends first. Reference coming soon.

std.mem

Low-level memory operations. Reference coming soon.

std.sync

Synchronization primitives beyond channels. Reference coming soon.

std.services

Service manager plus the builtin services - Application, Cache, Config, Diagnostics, Logging, Network, Runtime, Scheduler, Storage, UI and the rest. See the services reference for every method signature and the annotations each service ships.

Data

std.data

Encoding (JSON, XML, YAML, MsgPack, Base64, plus urlEncode/urlDecode percent encoding and htmlEncode/htmlDecode character references in std.data.encoding), compression in std.data.compress (DEFLATE with every level and window size, gzip, zlib and LZW), databases, and data structures. Reference coming soon.

std.crypto

Random numbers, UUIDs, keys and signatures (RSA, ECDSA, Ed25519, X25519), and PEM, PKIX and PKCS#8 encoding. std.crypto.hash has MD5, the SHA-1, SHA-2 and SHA-3 families, Keccak, BLAKE2, RIPEMD-160, CRC and Adler-32, plus HMAC and HKDF. std.crypto.cipher has AES, GCM and ChaCha20-Poly1305. std.crypto.x509 parses certificates and verifies chains for TLS. All of it is written in ADM.

std.formats

Readers and writers for file formats, written in ADM. Each family (images, audio, documents) shares one model, and options specific to a format are on that codec's own type. std.formats itself handles MIME types and content detection.

  • std.formats.image: PNG, APNG, GIF, JPEG, WebP, BMP, PCX, TGA, XPM, TIFF, PSD, ICO/CUR and ANI, with animation frames and EXIF.
  • std.formats.audio: WAV, AIFF, AU, FLAC, MP3, Ogg Vorbis, Opus, AAC and M4A/ALAC, plus MIDI and SoundFont files, a single tag model for all of them (with covers and ReplayGain), and rate and channel conversion. Decoded output matches ffmpeg.
  • std.formats.docs: a format-neutral Document with Markdown (CommonMark plus GFM), plain-text and RTF codecs.
  • std.formats.playlist: M3U/M3U8 and PLS.
  • std.formats.fonts: TrueType outlines and metrics.

Archives, video, spreadsheets and slides are designed but not built yet.

std.proto

Wire protocols. dbus.adm (Linux) speaks D-Bus: the message format (DBusWriter, DBusMessage), the SASL handshake and a DBusConnection to the session bus (dbusConnect, call, callSync, subscribe). Notifications is built on it.

Networking

std.net

Sockets, addresses and listeners, with typed NetError failures. The protocols on top are written in ADM:

  • std.net.tcp and std.net.udp: clients and servers.
  • std.net.tls: TLS 1.3 client and server.
  • std.net.http: HTTP/1.1 client and server with handlers, middleware, cookies, keep-alive and limits; .http2 (HTTP/2 with HPACK, served over TLS); .websocket (RFC 6455); .httptest (loopback test server and response recorder).
  • std.net.dns: DNS client and server with EDNS; .secure (DNS over TLS and over HTTPS); .dnssec (validation and zone signing, NSEC and NSEC3); .mdns (multicast DNS and DNS-SD service discovery).
  • std.net.url: URLs, query values, RFC 6570 templates and URL patterns.
  • std.net.multipart: multipart form bodies.

SSH, SMTP, FTP, LDAP and IRC are planned.

Media & Devices

std.media.player

A MediaPlayer that plays a Playlist of files, folders and internet radio streams (ICY titles, reconnects) through the default speaker or any sink. It plays gapless or with crossfades, and has shuffle, repeat, a play-next queue, ReplayGain, an effect chain, and a display for cover art or a visualizer. Playback runs on its own task. See the example.

std.media.dsp

Audio effects the player runs in a chain: biquad filters, parametric and graphic equalizers with presets, compressor, limiter, gain, balance, stereo width, reverb, delay and chorus, plus a spectrum analyzer and level meter.

std.media.synth

A software synthesizer: built-in waveforms per General MIDI group, or the samples of a SoundFont. Plays notes live or renders a MIDI file as an audio stream.

std.devices

Cameras over V4L2, and sound: Speaker and Microphone through PulseAudio or PipeWire, or raw ALSA when no sound server runs. Linux only for now.

Graphics & UI

std.ui

Components and renderers backing the UI constructs: events, the style model, the OpenGL renderer, and the layout dimensions px, %, vh, vw and em with their union Extent (see UI extents). Reference coming soon.

std.gfx

Raster, the pixel surface shared by images and canvases, plus masks and a Canvas. std.gfx.color covers color models, CSS parsing, blending and WCAG contrast. std.gfx.processing chains filters (blur runs on the GPU when there is one), transforms (resizing, content-aware seam carving, cropping around the main subject) and analysis in a Pipeline.

std.simd

Documented surface over the vector types - loads, stores, and lane operations. Reference coming soon.

std.gpu

DeviceBuffer<T>, memory that stays on the GPU between cuda def launches (upload, download, write, dispose), plus available() and deviceName(). See GPU kernels in the reference. Reference coming soon.

Tooling

std.testing

Lifecycle hooks and attributes for check suites. Reference coming soon.

std.reflection

Meta contexts, runtime type info, and discovery - the machinery behind attributes. Reference coming soon.

std.ide

Live service information for a connected IDE: the @ide annotation publishes a service method as a value, table, series, tree or text panel, refreshed on a schedule. Dormant unless the launcher sets ADM_IDE_PORT. Reference coming soon.

std.cli

Argument parsing, flags, and terminal output. Reference coming soon.

std.metrics

Counters, gauges, and metric publishing. Reference coming soon.

std.interop

Helpers for foreign function interfaces. Reference coming soon.
