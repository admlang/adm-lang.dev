Standard Library

The standard library ships with the compiler under the std namespace. Import any of it with use:

imports.adm 
use std.strings
use std.net.http
use std.data.encoding::(json)

Core

std.strings

formatC-style formatting (%d, %s, %x, …)
Scannercursor over text for hand-written parsers
similarity, SimilarityAlgorithmLevenshtein, Dice, Hamming, Jaro and Jaro-Winkler similarity

Most string operations are methods on string in the prelude.

Buffergrowable byte buffer, read and written

std.math

sqrt, sin, cos, atan2, ln, log2, log10, …numeric functions

Other operations are methods on the numeric types; exponentiation is **.
